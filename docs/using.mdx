Run `teaway`. That's it. The menu stays open across actions.

Passwordless setup is optional. The client asks before the first privileged change; macOS handles the hidden password prompt. Only do this on an account you trust.

<Frame>
  <img src="/images/shutdown.png" alt="Schedule a shutdown" />
</Frame>

After `brew upgrade teaway`, open the client. If the helper is stale, it offers repair.

## Scripts

| Command | Effect |
| --- | --- |
| `teaway on` | Keep this Mac awake |
| `teaway off` | Restore the sleep setting teaway owns |
| `teaway status` | Print awake, power, and shutdown state |
| `teaway shutdown after 2h` | One shutdown (`m` / `h` / `d`, 10 minutes–7 days) |
| `teaway shutdown cancel` | Cancel only that event |
| `teaway auth register` | Install the narrow passwordless helper |
| `teaway auth unregister` | Remove it |
| `teaway version` | Print the version |

`teaway status` and `teaway auth status` never ask for a password.
