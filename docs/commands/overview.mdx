teaway exposes a small, focused set of commands that cover the full power-management lifecycle of a headless or server Mac: enabling and restoring sleep settings, scheduling and cancelling a timed shutdown, inspecting current state, and setting up the optional passwordless helper. Every command maps to a single, auditable action with no hidden side effects.

## Command table

| Command | Effect |
|---|---|
| `teaway` | Open the interactive TUI client |
| `teaway on` | Snapshot the current sleep setting, disable sleep, verify, and record ownership |
| `teaway off` | Restore only the exact sleep setting owned by teaway |
| `teaway status` | Show power source, observed sleep state, ownership, and shutdown state |
| `teaway shutdown after DURATION` | Schedule one shutdown after an explicit bounded duration |
| `teaway shutdown status` | Reconcile the private shutdown record with macOS scheduled power events |
| `teaway shutdown cancel [ACTION_ID]` | Cancel only the exact teaway-owned shutdown event |
| `teaway auth status` | Inspect helper registration state and sudo Touch ID configuration |
| `teaway auth register` | Install the narrow passwordless helper after one administrator check |
| `teaway auth unregister` | Remove the helper and its sudoers rule |
| `teaway version` | Print the installed teaway version |

## Duration format

Duration arguments for `teaway shutdown after` require an explicit unit suffix. The accepted units are:

| Unit | Meaning | Example |
|---|---|---|
| `m` | Minutes | `30m` |
| `h` | Hours | `2h` |
| `d` | Days | `1d` |

Delayed shutdowns are bounded between a minimum of **10 minutes** and a maximum of **7 days**. teaway resolves the duration to an absolute local deadline and prints the timezone alongside the scheduled time so you always see exactly when the machine will shut down.

## Read-only commands

<Note>
`teaway status`, `teaway auth status`, and `teaway version` are read-only. They never request administrator authorization, never prompt for a password, and never mutate power state or scheduled events. You can run them freely on any account at any time.
</Note>

## Deprecated aliases

<Info>
`teaway tui` and `teaway interactive` are deprecated aliases for the no-argument `teaway` command. Both still work but are hidden from help output. Use `teaway` with no arguments to open the interactive client.
</Info>
