teaway never reads your password. When macOS asks, that prompt belongs to macOS.

There is no daemon, listener, account, or telemetry. Privileged work is a fixed `/usr/bin/pmset` call.

## Passwordless helper

The client can install a root-owned helper for this account only:

- `/Library/PrivilegedHelperTools/com.soundadam.teaway.helper.<uid>`
- `/etc/sudoers.d/soundadam-teaway-<uid>`

That rule covers `disablesleep` `0`/`1`, one teaway shutdown, and cancelling that event. Not a shell. Not arbitrary `pmset`.

<Warning>
  Any process running as your user can then perform those operations. Skip this on a shared account.
</Warning>

`brew upgrade` does not silently replace the helper. The client offers repair when versions diverge.

Homebrew builds from the GitHub source tag.

## Report a vulnerability

Use GitHub's **Report a vulnerability** form. Don't file a public issue. Details: [SECURITY.md](https://github.com/soundadam/teaway/blob/main/SECURITY.md).
