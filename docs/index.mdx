teaway gives your Mac a clear, reversible power contract: enable awake mode before walking away, and restore the exact sleep setting when you're done. Whether you're running a spare MacBook as a build box, a Mac mini as a home server, or a homelab node through a long backup job, teaway handles the power lifecycle — nothing more, nothing less.

## Get up and running

<Steps>
  <Step title="Install teaway">
    Install teaway through Homebrew using the `soundadam/tap` tap. No additional tools or accounts are required.

    ```sh
    brew install soundadam/tap/teaway
    teaway version
    ```
  </Step>
  <Step title="Inspect your baseline">
    Check authorization and power state before making any changes. This gives you a clear picture of what teaway will own.

    ```sh
    teaway auth status
    teaway status
    ```
  </Step>
  <Step title="Register the narrow helper (recommended)">
    For a trusted single-user account, register the helper once to avoid repeated password prompts on every privileged operation.

    ```sh
    teaway auth register
    ```
  </Step>
  <Step title="Enable awake mode">
    Verify remote access is working from a second device, then enable awake mode and confirm ownership.

    ```sh
    teaway on
    teaway status
    ```
  </Step>
  <Step title="Restore when done">
    When you no longer need awake mode, restore the exact sleep setting teaway snapshotted before it ran.

    ```sh
    teaway off
    teaway status
    ```
  </Step>
</Steps>
