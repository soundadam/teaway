`teaway` is the reversible power-control layer for a spare MacBook, a Mac mini home server, or a long job that must survive the end of a session. It manages sleep and one delayed shutdown. Remote access, networking, and the workload stay yours.

## Install and open the client

```sh
brew install soundadam/tap/teaway
teaway
```

No argument opens the client. It stays open so you can keep the Mac awake, allow sleep again, schedule or cancel a shutdown, and set up passwordless controls when a privileged action needs them.

Homebrew builds `teaway` from the GitHub source tag. Public releases do not ship an unnotarized prebuilt executable. Homebrew installs only `teaway`; the shorter `tea` name belongs to another package.

## What it does not do

`teaway` does not configure Remote Login, Screen Sharing, VPNs, firewalls, launchd, backups, or the workload. Confirm those independently before you close a lid or walk away.
