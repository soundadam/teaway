Full rules: [`CONTRIBUTING.md`](https://github.com/soundadam/teaway/blob/main/CONTRIBUTING.md).

```sh
git clone https://github.com/soundadam/teaway.git
cd teaway
go test ./...
go build -o teaway .
./teaway version
```

macOS 13+ and Go 1.24+. Tests must intercept privileged operations; CI never changes runner power settings.

Preview the docs site with `mint dev` from `docs/`. Client screenshots: `scripts/capture-client.sh` (needs [freeze](https://github.com/charmbracelet/freeze)).

Live site: [teaway.mintlify.app](https://teaway.mintlify.app).
