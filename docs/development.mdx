## Setup

macOS 13+ and Go 1.24+.

```sh
git clone https://github.com/soundadam/teaway.git
cd teaway
go test ./...
go build -o teaway .
./teaway version
```

## Boundary

`teaway` owns reversible power control and exact shutdown ownership. Do not add a hidden control plane, password handling, networking setup, or workload supervision.

The client is the operator manual. Do not add public pages that re-teach menu actions.

Automated tests must intercept privileged operations. CI must never change runner power settings, install the helper, or perform a real shutdown.

## Preview this site

From `docs/`, after you have Mintlify CLI access:

```sh
cd docs
mint dev
```

The live site is [teaway.mintlify.app](https://teaway.mintlify.app). Custom domains are configured later in the Mintlify dashboard; do not commit DNS secrets here.
